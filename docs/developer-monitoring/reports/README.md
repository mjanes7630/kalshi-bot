# Developer Monitoring Reports

Store one completed report per check in this folder.

Use this filename format:

```text
YYYY-MM-DD-your-name-check.md
```

Example:

```text
2026-08-23-alex-morning-check.md
```

Create reports from `../report-template.md`. Commit only your own uniquely
named report on your personal monitoring branch, then open a pull request.

Never commit secrets, `.env` content, private-key paths, API IDs, passwords,
or remote-access details.
